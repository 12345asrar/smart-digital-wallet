منظومة محفظة إلكترونية وخدمات مصرفية رقمية متكاملة مصممة لتسهيل المعاملات المالية، التحويلات، السحب النقدي، والدفع للتجار بأعلى معايير الأمان المالي.

---

### ✨ المميزات الرئيسية (Key Features)
1. **لوحة تحكم رصيد لحظية:** عرض الأرصدة المتعددة وسجل المعاملات المصرفية مع تحديثات فورية عبر السحابة.
2. **التحويلات المالية السريعة:** إرسال واستلام الأموال بين المستخدمين برقم الهاتف أو المعرّف مع التحقق المزدوج.
3. **تكامل بوابات البنوك (مثل بنك الكريمي):** دعم عمليات الإيداع والخصم المباشر عبر خدمات الربط المصرفي وتأكيد رمز التحقق (OTP).
4. **السحب النقدي بدون بطاقة (Cardless Cash-Out):** توليد رموز سحب مشفرة مؤقتة للاستلام عبر شبكة الصرافين والوكلاء.
5. **بوابة الوكلاء والتجار (Agent Portal):** واجهة مخصصة للوكلاء لتنفيذ وتأكيد عمليات الإيداع والسحب والتحقق من رموز العمليات.
6. **مسح الباركود و QR Code:** دفع فوري لمشتريات المتاجر والمطاعم.

---

### 🛠️ البنية التقنية (Tech Stack)
- **Frontend:** Flutter & Dart
- **Cloud Database:** Google Cloud Firestore
- **Authentication:** Firebase Auth & Mobile Verification
- **Scanner:** Mobile Scanner (QR & Barcode)
- **Services:** BankGatewayService & WalletTransactionEngine
